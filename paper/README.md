# Manuscript

IEEE journal format (`IEEEtran`, `journal` option), targeting **RA-L (+IROS 2027)
for Paper A** and **T-RO for Paper B** (decision D1 in `docs/PLAN.md`).

```bash
make            # -> build/main.pdf (latexmk)
make check      # citation hygiene (draft mode: warns on unverified entries)
make submission-check   # fails on unverified cited entries or leftover \todo / \draftnote
```

## Layout

| Path | Content |
|---|---|
| `main.tex` | Preamble, notation macros, section includes |
| `sections/*.tex` | One file per section (edit in parallel without conflicts) |
| `references.bib` | Every entry is preceded by `% status: ...` (see AGENTS.md §5) |
| `figures/` | Generated figures (PDF/PNG) produced by scripts. Keep the source script next to them, never hand-edited |
| `data/` | CSV/JSON written by `experiments/` scripts. **The only source of numbers in the paper** |

## Rules

1. **Numbers.** Every number in the text, tables, or figures comes from
   `paper/data/` (generated by a script under `experiments/`) and records the
   commit hash and seeds. Never type a result by hand.
2. **Citations.** Upgrade `verified-web` / `UNVERIFIED` entries to `verified`
   by opening the DOI or publisher page. Record the source in the status line.
3. **Claims.** Any "first" or "novel" claim must match a `confirmed` row in
   `docs/research/gap_analysis.md` §4.
4. **Sim vs. real.** State the tier (fast sim, Gazebo, real data) for every result.

## Pre-submission checklist (Reviewer-2 pass, task T-P6-01)

- [ ] Every contribution in the intro is backed by an experiment or proof.
- [ ] Closest work (*Above and Below*, DRACo-SLAM2, SlideSLAM, Kimera-Multi) is compared fairly.
- [ ] Baselines were tuned per their authors; any adaptation is documented.
- [ ] ≥ 10 seeds, 95 % CIs, and a paired test against the strongest baseline.
- [ ] Failure cases and limitations are reported (e.g. aliasing, no overlap, sim-to-real gap).
- [ ] `make submission-check` passes; all figures are vector graphics or ≥ 300 dpi.
- [ ] Code, data, and the benchmark are released with a tagged commit referenced in the paper.
- [ ] Supplementary video prepared.
